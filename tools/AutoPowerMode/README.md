# AutoPowerMode

Лёгкая фоновая утилита для ноутбуков Lenovo: когда запускается игра, переключает
режим работы на **«Производительность»**, когда игра закрывается — на
**«Сбалансированный»** (или другой, заданный в конфиге).

Переключение идёт через тот же WMI-интерфейс, что использует Lenovo Vantage и
клавиша **Fn+Q**: `root\WMI → LENOVO_GAMEZONE_DATA → SetSmartFanMode`.

## Что важно

- Работает **только на Lenovo Gaming** (LOQ / Legion), где доступен
  `LENOVO_GAMEZONE_DATA`. На других ноутбуках WMI просто не найдётся.
- Переключение происходит **только на переходе** «игра началась» / «игра
  закончилась». Если во время игры нажать Fn+Q и выбрать другой режим, утилита
  не будет возвращать свой режим каждую секунду — ручной выбор не перебивается.
- По умолчанию включает производительность **только от розетки**. На батарее
  остаётся текущий режим. Это отключается в конфиге или в меню трея.
- Не меняет кривые вентиляторов, лимиты питания и настройки BIOS — только
  профиль `SetSmartFanMode` (1/2/3/255), как Fn+Q.
- WMI-метод Lenovo надёжно работает из процесса с правами администратора,
  поэтому автозапуск сделан через планировщик задач с параметром
  «Выполнять с наивысшими правами».

## Установка

1. Собрать (нужен .NET 8 SDK):

   ```powershell
   cd D:\launcher\tools\AutoPowerMode
   .\Build.ps1
   ```

2. Установить:

   ```powershell
   .\Install.ps1
   ```

   Скрипт:
   - копирует программу в `%LOCALAPPDATA%\AutoPowerMode`;
   - создаёт задачу планировщика `AutoPowerMode` с автозапуском при входе
     в систему (через 10 секунд);
   - запускает утилиту.

3. Готово. Иконка появляется в трее.

Удаление:

```powershell
cd D:\launcher\tools\AutoPowerMode
.\Uninstall.ps1
```

`Uninstall.ps1` оставляет `config.json` и журнал. Полное удаление:

```powershell
.\Uninstall.ps1 -RemoveData
```

## Как определяется игра

Опрос раз в 2 секунды (настраивается). Игрой считается процесс, у которого:

1. есть видимое окно на переднем плане, занимающее не меньше
   `MinWindowCoveragePercent` процентов монитора (по умолчанию 60 %); **и**
2. загрузка **3D-движка GPU именно этим процессом** не ниже
   `GpuThresholdPercent` (по умолчанию 7 %); **или** Windows сообщает о
   полноэкранном D3D-приложении.

Игра в маленьком окне тоже распознаётся: если процесс занимает не меньше
половины 3D-движка GPU (50 %) и у него есть видимое окно, покрытие экрана уже
не важно. Лёгкие приложения под это правило не попадают.

Дополнительно:

- список исключений (`ExcludeProcesses`) отсекает браузеры, видеоплееры,
  лаунчеры, Discord, редакторы и т.п.;
- `ExtraGameProcesses` — принудительный список: процесс с таким именем
  считается игрой, даже если эвристика его не поймала. Сюда можно добавить
  exe игры, если она использует нестандартное окно или лаунчер.

Пока игра запущена, утилита держит режим, даже если вы свернули игру или
переключились в браузер: сессия живёт, пока процесс нагружает 3D-движок GPU.
Режим возвращается после выхода из игры (процесс завершился) через
`EndDelaySeconds`.

## Настройки

Файл: `%LOCALAPPDATA%\AutoPowerMode\config.json` (или рядом с exe при ручном
запуске). После правки выберите в меню трея **«Перезагрузить настройки»** или
перезапустите утилиту.

| Параметр | По умолчанию | Что значит |
|---|---:|---|
| `Enabled` | `true` | Главный выключатель. |
| `RequireAcPower` | `true` | Переключать на производительность только при питании от сети. |
| `GameMode` | `3` | Режим во время игры: 1 — тихий, 2 — сбалансированный, 3 — производительность, 255 — пользовательский. |
| `ExitMode` | `2` | Режим после игры: `0` — вернуть тот, что был до игры; 1/2/3/255 — фиксированный. |
| `StartDelaySeconds` | `3` | Сколько секунд игра должна продержаться, прежде чем включить производительность. |
| `EndDelaySeconds` | `6` | Задержка перед возвратом режима после выхода. |
| `PollIntervalMs` | `2000` | Период опроса, мс (1000–15000). |
| `GpuThresholdPercent` | `7.0` | Порог загрузки 3D-движка GPU процессом, %. |
| `MinWindowCoveragePercent` | `60.0` | Минимальная доля экрана, которую должно занимать окно, %. |
| `RetrySeconds` | `30` | Пауза между повторными попытками, если WMI не ответил. |
| `VerboseLogging` | `false` | Подробный журнал (какие окна видит детектор). |
| `ExtraGameProcesses` | `[]` | Имена процессов без `.exe`, которые всегда считаются игрой. |
| `ExcludeProcesses` | большой список | Имена процессов без `.exe`, которые никогда не считаются игрой. |

Пример: добавить игру, которая не определяется:

```json
"ExtraGameProcesses": [ "MyGame", "MyGameLauncher" ]
```

## Меню в трее

- **Игровой режим** — включить/выключить автоматику.
- **Только от розетки** — учитывать питание от сети или нет.
- **Сейчас / Игры** — текущее состояние и обнаруженные процессы.
- **Открыть настройки** — открыть `config.json`.
- **Открыть журнал** — показать файл журнала в проводнике.
- **Перезагрузить настройки** — применить изменения без перезапуска.
- **Выход** — завершить; если был включён игровой режим, вернуть
  `ExitMode`.

Двойной клик по иконке открывает конфиг.

## Журнал и диагностика

Журнал:

```
%LOCALAPPDATA%\AutoPowerMode\logs\auto-power-mode.log
```

Диагностика (что видит детектор: окна, pid, покрытие экрана, загрузку GPU).
Перед запуском закройте работающую утилиту из меню трея — второй экземпляр
не стартует:

```powershell
& "$env:LOCALAPPDATA\AutoPowerMode\AutoPowerMode.exe" --diagnose
```

Отчёт появится в:

```
%LOCALAPPDATA%\AutoPowerMode\logs\diagnostics.txt
```

## Требования

- Windows 10/11 x64.
- Lenovo Gaming с установленным драйвером Lenovo GameZone (обычно уже есть
  вместе с Lenovo Vantage / Legion Zone).
- .NET 8 Desktop Runtime (на машинах с Nexora он уже установлен). Для сборки
  без зависимости от runtime используйте `.\Build.ps1 -SelfContained`.

## Ограничения

- Не работает на не-Lenovo ноутбуках и на моделях без `LENOVO_GAMEZONE_DATA`.
- UWP-игры (редкие, из Microsoft Store) могут не определяться: их окно
  принадлежит `ApplicationFrameHost`.
- Античит-защищённые процессы иногда не отдают имя процесса; для них можно
  использовать `ExtraGameProcesses`.
- Если ноутбук работает от недостаточно мощного адаптера питания, прошивка
  может сама не включить «Производительность». Это ограничение Lenovo, не
  утилиты.
- Утилита не запускает игры и не вмешивается в их работу; она только меняет
  профиль питания.

## Сборка

```powershell
.\Build.ps1                 # framework-dependent, один exe (~1 МБ + .NET 8)
.\Build.ps1 -SelfContained  # автономная сборка, больше по размеру
```

Результат — в `publish/`. Для установки используйте `Install.ps1`.

```
  config.json
  icons/
```
