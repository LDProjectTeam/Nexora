# Vellum Migrator

Отдельный переносимый exe для перехода с Nexora на Vellum.

## Что делает

1. Находит старый профиль `%APPDATA%\Nexora` (или `%APPDATA%\GameVault`).
2. Находит старую установку: стандартную папку, `Nexora`/`GameVault` в корне любого диска, `Programs\Nexora`, `%ProgramFiles%` или запись в реестре.
3. Переносит профиль в `%APPDATA%\Vellum`:
   - копирует все остальные файлы (артворк, кэш, торренты, логи);
   - объединяет `settings.json` и `library.json`, не затирая уже добавленные в Vellum игры;
   - старый профиль переименовывается в `Nexora.backup` (или `GameVault.backup`), чтобы Vellum не создавал дубликаты при старте.
4. Переносит пользовательские данные из старой папки в папку установленного Vellum:
   - `Library` перемещается в `<папка Vellum>\Library` (на том же диске — мгновенно, между дисками — копированием);
   - `data` и `tools` объединяются с установленными;
   - в `settings.json` и `library.json` обновляются пути на новую библиотеку.
5. Если Vellum не установлен, скачивает последнюю версию с GitHub Releases (резервный источник — `releases.json` сайта) и ставит её тихо в выбранную папку.
6. По желанию удаляет старую версию Nexora.
7. По желанию запускает Vellum.

Старые данные не удаляются, пока не будут успешно скопированы. Резервные копии `settings.json` и `library.json` сохраняются рядом как `*.pre-migration`.

## Куда установится Vellum

- По умолчанию: `%LocalAppData%\Programs\Vellum` (например, `C:\Users\<имя>\AppData\Local\Programs\Vellum`).
- В окне мигратора путь можно изменить кнопкой «Обзор…».
- Галочка «Установить в папку Nexora» подставляет старый каталог (например, `D:\Nexora`) и включает удаление старой версии. Перед установкой `data` и `tools` сохраняются и затем возвращаются на место.
- Выбранный путь передаётся установщику как `/DIR="..."`.

## Сборка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\migrator\Build-Migrator.ps1
```

Результат: `artifacts\migrator\Vellum-Migrator.exe` (single-file, self-contained, win-x64).

## Запуск

Обычный запуск открывает окно с найденными путями и флажками.

Тихий режим:

```powershell
.\Vellum-Migrator.exe --silent
.\Vellum-Migrator.exe --silent --uninstall-old --no-launch
.\Vellum-Migrator.exe --silent --dry-run
```

| Параметр | Значение |
|---|---|
| `--silent` | без окна, результат в журнал и код возврата |
| `--dry-run` | только показать план, ничего не менять |
| `--no-profile` | не переносить профиль |
| `--no-data` | не переносить `Library`, `data` и `tools` из старой папки |
| `--no-library` | не переносить папку `Library` |
| `--copy-library` | скопировать `Library`, а не переместить |
| `--no-download` | не скачивать установщик автоматически |
| `--uninstall-old` | удалить старую версию Nexora |
| `--no-launch` | не запускать Vellum после переноса |
| `--installer <path>` | явно указать `Vellum-Setup-*.exe` |
| `--install-dir <path>` | куда установить Vellum (передаётся setup как `/DIR`) |
| `--roaming <path>` | другой каталог профилей (для проверки) |
| `--install-root <path>` | другой каталог установки (для проверки) |
| `--log <path>` | файл журнала |
| `--help` | справка |

Журнал по умолчанию: `%TEMP%\Vellum-Migrator.log`.

## Безопасность

- Профиль копируется, а старая папка профиля переименовывается в резервную копию.
- `Library` перемещается; при ошибке копирования старая папка остаётся. `--copy-library` оставляет её целиком.
- Существующие файлы в `%APPDATA%\Vellum` не теряются: JSON объединяется, остальное обновляется с резервной копией.
- Удаление старой версии выключено по умолчанию и может запросить UAC.
- Удаление старой версии пропускается, если библиотеку не удалось перенести.
